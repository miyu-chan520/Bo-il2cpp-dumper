# Security Policy

## Scope

Please report security issues in this repository's build scripts, CI configuration, or native module code privately when the repository's GitHub private vulnerability reporting feature is available. If it is not enabled, contact the maintainers through a private channel rather than publishing exploit details in a public issue.

## What to include

- A concise description and potential impact.
- Affected file, commit, and build environment.
- Minimal reproduction steps that do not require distributing proprietary application data.
- A suggested mitigation, if known.

Please do not attach app-private data, account information, signing keys, tokens, or proprietary dumps.

## Authorized testing

Only test applications and devices for which you have permission. This project does not authorize bypassing anti-cheat, defeating access controls, or extracting third-party data.
